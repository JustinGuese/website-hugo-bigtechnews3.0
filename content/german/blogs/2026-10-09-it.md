Microsoft baut GitHub Copilot um und macht lokale Hardware zu einer primären Inferenzebene. Im Rahmen der Initiative [Project HydraFusion](https://ecommerce-api.datafortress.cloud/r/brieftechnews/DBeIuFYyfN6nzfyoiaO0hA/djF8d2VifDIwMjYtMTAtMDktaXR8bWljcm9zb2Z0LXZlcnRlaWx0LWdpdGh1Yi1jb3BpbG90LWF1Zi1sb2thbGUtcnR4LXNwYXJrLWNoaXBzfHxodHRwczovL2NvbW1hbmRsaW5lLm1pY3Jvc29mdC5jb20vbG9jYWwtbW9kZWxzLXNhbmRib3hlZC10b29scy1naXRodWItd2luZG93cy8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) teilt Copilot Workloads automatisch zwischen gehosteter Infrastruktur und On-Device-GPUs auf - basierend auf Systemlast, Latenzspielraum und Aufgabenkomplexität.

Die On-Device-Komponente basiert auf einer quantisierten Variante von MAI Code 1.1 Flash, optimiert für Workstations wie das Surface Laptop Ultra mit NVIDIA-RTX-Spark-Chips. Diese Systeme bieten rund 1 PFLOP an Rechenleistung sowie bis zu 128 GB Unified Memory. Dadurch verbleiben große Programmiermodelle resident im VRAM, ohne den Arbeitsspeicher des Hosts zu überlasten. Für den sicheren Zugriff dieser lokalen Modelle auf das Hostsystem führt Microsoft die Microsoft Execution Containers (MXC) ein. MXC dient als Sandbox auf Betriebssystemebene, die lokale Shell-Aufrufe, Debugging-Server und Dateizugriffe isoliert, Netzwerk-Egress reduziert und Systemanmeldedaten abschirmt.

Amazon Web Services hat [Strands Box](https://ecommerce-api.datafortress.cloud/r/brieftechnews/ckVFnjmH7TyVaBkdBTJJbg/djF8d2VifDIwMjYtMTAtMDktaXR8YXdzLXZlcsO2ZmZlbnRsaWNodC1zdHJhbmRzLWJveC16dXItYWJzaWNoZXJ1bmctdm9uLWNsaS1hZ2VudGVufHxodHRwczovL3d3dy50aGVyZWdpc3Rlci5jb20vYWktYW5kLW1sLzIwMjYvMTAvMDcvYXdzLWxhdW5jaGVzLW9wZW4tc291cmNlLWFpLWFnZW50LXNhbmRib3gtdG8tcHJldmVudC15b2xvLW1vZGUtZGlzYXN0ZXJzLzUzMDE2ODc_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) vorgestellt, ein quelloffenes Isolations-Framework, das unsichere Aktionen von Agenten abfängt, bevor sie die Host-Umgebung erreichen. Das Framework kapselt Laufzeitumgebungen - darunter die Dogwood Local Engine, die Strands Shell und lokale Python-Interpreter - in ephemeren Umgebungen mit zustandsabhängiger Richtliniendurchsetzung.

Im Gegensatz zu einfachen Berechtigungsgrenzen erfasst die Policy-Engine von Strands Box auch zeitliche Abläufe und überwacht Befehlsfolgen statt isolierter Einzelaktionen. Sie blockiert anomales Verhalten - etwa wenn ein Agent innerhalb desselben Durchlaufs Zugangsdaten generiert, eine Datei modifiziert und einen ausgehenden Slack-Webhook ausführt. Für Infrastruktur-Ingenieure, die unbeschränkte Evaluierungsschleifen oder Agenten mit Tool-Zugriff lokal ausführen, bietet das Framework einen auditierbaren Schutzwall gegen versehentliche Dateilöschungen und unautorisierte API-Aktualisierungen.
