[Stripes WebMCP](https://ecommerce-api.datafortress.cloud/r/brieftechnews/q_am4Ze4BP4s92cPNJXvlg/djF8d2VifDIwMjYtMDktMjMtZm91bmRlcnN8ZGlnaXRhbG9jZWFuLW1hbmFnZWQtYWdlbnRzLXVuZC1zdHJpcGUtd2VibWNwfHxodHRwczovL2RvY3Muc3RyaXBlLmNvbS9hZ2VudGljLWNvbW1lcmNlL2Zvci1hZ2VudHMvd2VibWNwP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) ist experimentell, aber clever: Browser-Agenten rufen strukturierte Tools auf, die in Stripe-Zahlungs-UIs registriert sind, statt Seiten zu scrapen und Klicks zu simulieren. Agenten sollten Tools zur Laufzeit entdecken und bei Bedarf auf Standard-Automatisierung zurückfallen. Es ist früh, aber es ist der erste glaubwürdige Versuch, Browser-basierte Zahlungen zuverlässig statt instabil zu machen.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/Sk5gxMco3KhpzwpQsdz_1A/djF8d2VifDIwMjYtMDktMjMtZm91bmRlcnN8c2xvcC1ncmFuYXRlbi11bmQtZGllLXJldmlldy1zdGV1ZXJ8fGh0dHBzOi8vd3d3LmJsb2c0ZW1zLmNvbS9wL3Nsb3AtZ3JlbmFkZXM_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t" target="_blank" rel="noopener noreferrer">Source: blog4ems.com ↗</a></p>

[Shopify-CEO Tobias Lütke prägte „Slop-Granaten“](https://ecommerce-api.datafortress.cloud/r/brieftechnews/Sk5gxMco3KhpzwpQsdz_1A/djF8d2VifDIwMjYtMDktMjMtZm91bmRlcnN8c2xvcC1ncmFuYXRlbi11bmQtZGllLXJldmlldy1zdGV1ZXJ8fGh0dHBzOi8vd3d3LmJsb2c0ZW1zLmNvbS9wL3Nsb3AtZ3JlbmFkZXM_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) für KI-generierten Code, den der Autor nicht versteht und an einen Reviewer weitergibt. Bei Shopify stammte etwa einer von acht gemergten Pull Requests vom internen KI-Agenten River. Das Problem: Der Einreicher kann die Entscheidungen hinter dem Code nicht erklären, also müssen Reviewer herausfinden, was vertrauenswürdig ist, und manchmal dem Autor beibringen, was sein eigener Code tut.

Die Zeit, die beim Generieren des Codes gespart wird, wird zur Arbeit von jemand anderem. Wenn du KI-generierte Pull Requests reviewst, zahlst du diese Steuer. Die Lösung ist ein Prozess: Verlange, dass Autoren ihren KI-generierten Code erklären, bevor er ins Review geht - sonst verschiebst du die Kosten nur auf die erfahrensten Leute im Team.
