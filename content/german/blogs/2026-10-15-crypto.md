For crypto operators, the risk is structural. Exchanges that serviced UK IP addresses or marketed derivatives locally without FCA sign-off face retroactive liability. Regents Labs [open-sourced an application framework](https://ecommerce-api.datafortress.cloud/r/brieftechnews/R8UEHXneRPPHDgwIOnf2kA/djF8d2VifDIwMjYtMTAtMTUtY3J5cHRvfHJlZ2VudHMtbGFicy1kcm9wcy1lbGl4aXItc3RhY2stZm9yLWF1dG9ub21vdXMtd2VibWNwLXBheW1lbnRzfHxodHRwczovL2xpbmtzLnRsZHJuZXdzbGV0dGVyLmNvbS9iOHpuZjI_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) called `ash-template`, designed to host backend services queried exclusively by autonomous AI agents. Built on Elixir, Phoenix, and AshPostgres, the stack abandons common Node.js/Python architectures in favor of the BEAM virtual machine's concurrency model to handle low-footprint agent traffic at scale.

The stack bundles three core operational layers:
- **WebMCP**: Exposes internal application endpoints, tools, and page state directly to autonomous agents via structured protocols.
- **SIWA (Sign-In with Agent)**: Handles agent-level cryptographic authentication and sybil defense, separating human users from automated processes. Privy handles the human auth layer.
- **x402 Protocol**: Replaces subscription paywalls with instant stablecoin micropayments, letting software agents pay for individual API calls and compute units over HTTP response codes.

The repository is running live across five production applications. Regents Labs, which operates without VC backing, diverts all platform fees generated by the underlying services to its $REGENT token staking pool.

In Uniswap v3, liquidity positions are wrapped in non-fungible tokens (ERC-721), fracturing onchain composability and forcing liquidity providers to manually claim, swap, and restake accumulated fees. Pair Tokens use a v4 hook to execute a public, permissionless `compound()` function. This mechanism pulls uncollected swap fees, trades them into the correct pool ratios, and pushes them back into the underlying pool to increase capital depth.

Retaining the ERC-20 interface means these auto-compounding positions can be used directly as collateral in money markets, paired in secondary automated market makers, or traded without unwrapping.
