Microsoft and Intel just made the kind of announcement that quietly reshapes what you can rent in Azure for the next five years. Microsoft is the first customer for Intel Foundry's EMIB advanced packaging, has locked in multi-year Xeon supply including the upcoming Diamond Rapids CPUs, and is collaborating on CXL memory, QuickAssist, and TDX confidential computing. The claimed numbers are the headline: up to 2.3x performance for Azure M-series v4 VMs with CXL and Flat Memory Mode, and up to 2.5x faster SQL backups with QAT-enabled VMs.

This isn't just a press release about a nice partnership. For anyone sizing workloads, the M-series v4 numbers mean the memory-bandwidth bottleneck just got a lot cheaper to address.

[Microsoft introduced agent controls](https://ecommerce-api.datafortress.cloud/r/brieftechnews/IXsqBaGLkjk2Y_jQhb3_lw/djF8d2VifDIwMjYtMTEtMjAtaXR8bWljcm9zb2Z0cy1hZ2VudC1jb250cm9scy1hLWNvbnRyb2wtcGxhbmUtZm9yLWJlaGF2aW9yfHxodHRwczovL2NvbW1hbmRsaW5lLm1pY3Jvc29mdC5jb20vaW50cm9kdWNpbmctYWdlbnQtY29udHJvbHMtYW4tZW50ZXJwcmlzZS1jb250cm9sLXBsYW5lLWZvci1hZ2VudC1iZWhhdmlvci8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t), a managed Azure service for centrally defining and evaluating policies governing AI agent behavior across frameworks and clouds. It's built on the open-source Agent Control Specification (ACS) and Agent Hooks, which define intervention points across the agent lifecycle: startup, input, model calls, tool calls, output, shutdown.

The evaluation stack uses content safety classifiers, LLM judges, and deterministic Rego rules. For engineers, this addresses the gap between safe answers and safe actions - a model can give a good response, but the thing that takes an action needs a policy layer that can stop it. The managed service angle means you don't have to build that policy infrastructure yourself.

[Google built and open-sourced Sashiko](https://ecommerce-api.datafortress.cloud/r/brieftechnews/OPZH7-Mo52aEEGhC2YRPbg/djF8d2VifDIwMjYtMTEtMjAtaXR8c2FzaGlrby10aGUtY29kZS1yZXZpZXdlci10aGF0LXNjYWxlc3x8aHR0cHM6Ly9jbG91ZC5nb29nbGUuY29tL2Jsb2cvcHJvZHVjdHMvYXBwbGljYXRpb24tZGV2ZWxvcG1lbnQvbGVzc29ucy1mcm9tLWJ1aWxkaW5nLXNhc2hpa28tYW4tYWdlbnRpYy1jb2RlLXJldmlldy1zeXN0ZW0_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t), an agentic code review system powered by Gemini, donated to the Linux Foundation. The Linux kernel spans over 35 million lines of code with over 85,000 changes per year, and maintainers manually review patches to catch memory leaks, deadlocks, race conditions, and security bugs.

The system separates bug finding from verification using parallel specialist sessions and per-bug deep checks. The production data is the headline: seven months of use on kernel mailing lists shows Sashiko completes about 1,200 reviews daily and correlates with a 35 percent drop in 60-day follow-up fixes for merged commits. This is the proof point that code review, not code generation, is the real bottleneck in large open-source projects.

[Amazon CloudFront Functions now supports network calls](https://ecommerce-api.datafortress.cloud/r/brieftechnews/GinjJjobSHBnbXzAFu-wmw/djF8d2VifDIwMjYtMTEtMjAtaXR8Y2xvdWRmcm9udC1mdW5jdGlvbnMtZ3Jvd3Mtc29tZS1sZWdzfHxodHRwczovL2F3cy5hbWF6b24uY29tL2Fib3V0LWF3cy93aGF0cy1uZXcvMjAyNi8xMS9jbG91ZGZyb250LWZ1bmN0aW9ucy1uZXR3b3JrLWNhbGxzLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) via new cf.fetch() and cf.beacon() methods, allowing lightweight JavaScript at edge locations to call APIs and act on responses in real time. This closes a significant gap - previously, CloudFront Functions were for simple transforms, and anything requiring an upstream call meant a more expensive Lambda@Edge or a round trip to the origin.
