NVIDIA dropped the [Open Agent Safety Platform](https://ecommerce-api.datafortress.cloud/r/brieftechnews/VK2EOw0irB_G2T1hndJw5w/djF8d2VifDIwMjYtMDktMjktYWl8bnZpZGlhLXdhbnRzLXRvLWJlLXRoZS1zZWF0YmVsdC1mb3ItYWktYWdlbnRzfHxodHRwczovL252aWRpYW5ld3MubnZpZGlhLmNvbS9uZXdzL29wZW4tYWdlbnQtc2FmZXR5LXBsYXRmb3JtP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) today, and it is not another model card. The platform pairs OpenShell, an open-source software toolkit, with Sentry, a reference design for hardware. The pitch is full-stack agent security: memory, tool execution, and the model layer, all the way down to the silicon.

This matters because the industry has been bolting security onto agents after the fact. Recent incidents have shown that a prompt injection in a tool call or a poisoned memory can turn a well-behaved agent into a data exfiltration vector. Sentry gives you a hardware anchor so that trust decisions aren't just soft logic in the application layer. If you are running agents in production and your security story is "we filter the prompts," this is the upgrade path.
