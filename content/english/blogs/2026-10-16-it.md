Microsoft is overhauling the memory manager in Windows 11 to address low-tier enterprise laptops running out of headroom. The shell update lets the kernel keep up to 2GB more working state resident in physical RAM before triggering paging routines to disk, boosting responsiveness across core applications by up to 20%.

On machines with 8GB of memory or less, Windows 11 will now refuse to initialize the Widgets subsystem on boot, immediately clawing back over 200MB of RAM. For IT departments managing budget enterprise fleets, it is a rare case of an OS vendor reducing idle memory bloat rather than expanding it.

Meanwhile, enterprise security teams have an immediate fire drill. Google has warned that suspected China-linked threat actors are actively probing for vulnerable self-hosted BeyondTrust Remote Support instances, following targeted attacks discovered earlier this summer.

Apple’s systems engineering team published a design paper on [Minions](https://ecommerce-api.datafortress.cloud/r/brieftechnews/KbhHbdBNlRq-srC6eTgA7Q/djF8d2VifDIwMjYtMTAtMTYtaXR8YXBwbGUtdHVybnMtaWRsZS1lbXBsb3llZS1tYWNzLWludG8tYW4taW5mZXJlbmNlLWNsdXN0ZXJ8fGh0dHBzOi8vd3d3LmNvbXB1dGVyd29ybGQuY29tL2FydGljbGUvNDIzNTkwMS9hcHBsZXMtbWluaW9ucy10ZWNoLXR1cm5zLWlkbGUtbWFjcy1pbnRvLWFuLWFpLWRhdGEtY2VudGVyLmh0bWw_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t), an internal distributed architecture that harvests spare Apple silicon compute across corporate desks. 

The architecture consists of three components:
- **Minion Server:** Tracks node availability, slices workloads, and handles queue state.
- **Executor:** A lightweight background daemon on client hardware that spawns Hugging Face or Ollama instances inside unified memory.
- **Watchdog:** Monitors local user interaction; if an employee moves their mouse or launches a local process, the node drops inference instantly and hands uncompleted chunks back to the central queue.

Apple is using the system for batch vector embeddings and background model evaluation, with distributed fine-tuning planned next. While not an external commercial product, the setup demonstrates how organizations with massive internal Apple silicon deployments can extract compute from unused workstation RAM overnight.
