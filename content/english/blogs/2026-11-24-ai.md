[Z.ai's GLM-5.4](https://ecommerce-api.datafortress.cloud/r/brieftechnews/JPeMertodBUlqbnOAk_Zcw/djF8d2VifDIwMjYtMTEtMjQtYWl8Z2xtLTU0LXJldXNlcy1sYXllcnMtaW5zdGVhZC1vZi1hZGRpbmctdGhlbXx8aHR0cHM6Ly96LmFpL2Jsb2cvZ2xtLTUuND91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) is the first flagship built on a Loop Transformer. The architecture reuses a shared block of layers, looping through it multiple times to reason more deeply. No new parameters per loop - the same weights get applied repeatedly.

The claim is that this reaches intelligence comparable to 2T to 3T parameter models. That's a bold statement, and the obvious engineering trade-off is compute per token: looping through the same block costs more FLOPs per forward pass even if the parameter count stays flat. It's available now on the GLM Coding Plan, so the benchmarks are testable. For anyone running inference at scale, the question isn't whether it's smart - it's whether the loop cost per token beats just renting a bigger model.

[Google Research's DeepCrossAttention](https://ecommerce-api.datafortress.cloud/r/brieftechnews/bU5gpMN6dMD1BQusWeFeUw/djF8d2VifDIwMjYtMTEtMjQtYWl8ZGVlcGNyb3NzYXR0ZW50aW9uLW1ha2VzLXJlc2lkdWFsLWNvbm5lY3Rpb25zLWxlYXJuYWJsZXx8aHR0cHM6Ly9yZXNlYXJjaC5nb29nbGUvYmxvZy9zdXBlcmNoYXJnaW5nLXRyYW5zZm9ybWVyLXJlc2lkdWFsLWNvbm5lY3Rpb25zLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) (DCA) reworks the transformer's residual stream. Instead of a fixed addition from the previous layer, DCA uses learnable weights and depth-wise cross-attention to dynamically combine outputs from earlier layers. This stops information dilution as networks get deeper.

The result: same quality up to three times faster during training, with negligible parameter increase. It also cuts parameter count by 30-40% compared to standard residual setups. This directly attacks the vanishing gradient problem in deep networks. If this holds up on large-scale runs beyond C4 and LM1B, it's a drop-in replacement for the residual block in most transformer implementations.

[SELFWRITE](https://ecommerce-api.datafortress.cloud/r/brieftechnews/n-aRjdDTls_BNufn5k-yjg/djF8d2VifDIwMjYtMTEtMjQtYWl8c2VsZndyaXRlLWxsbXMtZWRpdC10aGVpci1vd24td2VpZ2h0cy13aXRob3V0LWdyYWRpZW50c3x8aHR0cHM6Ly9hcnhpdi5vcmcvYWJzLzI2MTEuMjk1MTM_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) from a new paper flips the training paradigm. Instead of gradient descent writing weight updates, the model itself programs a low-rank weight edit. Each generation, the model studies its own reasoning, inspects its weights and activations in a persistent Python session, and writes a program that constructs the edit. The edit is graded and merged only if it improves.

On Qwen3.8-27B and DAPO-Math, five generations raised gate accuracy from 73.95% to 76.45% and held-out test accuracy from 76.30% to 77.75%. No gradient step anywhere. This is early and small, but it's the first credible demonstration that models can author useful weight changes from white-box introspection alone.
