<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/UPnGbCT4eeY-ukx8eXhv8g/djF8d2VifDIwMjYtMTAtMjItaXR8cGhpc2hpbmctY2FtcGFpZ25zLXBpdm90LXRvLWdjcC1sbG1qYWNraW5nfHxodHRwczovL3d3dy53aXouaW8vYmxvZy9mcm9tLXBoaXNoaW5nLXRvLWxsbWphY2tpbmc_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t" target="_blank" rel="noopener noreferrer">Source: wiz.io ↗</a></p>

Cloud security researchers at Wiz CIRT detailed an emerging attack vector dubbed [LLMjacking targeting Google Cloud accounts](https://ecommerce-api.datafortress.cloud/r/brieftechnews/UPnGbCT4eeY-ukx8eXhv8g/djF8d2VifDIwMjYtMTAtMjItaXR8cGhpc2hpbmctY2FtcGFpZ25zLXBpdm90LXRvLWdjcC1sbG1qYWNraW5nfHxodHRwczovL3d3dy53aXouaW8vYmxvZy9mcm9tLXBoaXNoaW5nLXRvLWxsbWphY2tpbmc_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t). Attackers phish corporate credentials and MFA tokens, gain administrative access to cloud environments, and modify resource policies to link external, attacker-controlled GCP projects directly to the victim’s internal Cloud Billing account.

The primary target is quota for high-end LLM inference, specifically Gemini API endpoints. Because the actual compute workloads and prompts execute within the attacker's foreign GCP project, the victim's internal Cloud Logging and audit trails show zero prompt contents or model requests. Victims only notice the compromise when unexpected billing alerts spike into hundreds of thousands of dollars within days. Security teams must restrict `billing.resourceAssociations.create` permissions and enforce org-level policies blocking billing exports to external project IDs.
