<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/sL_ljMKSjUS3YdVZI1do7w/djF8d2VifDIwMjYtMTEtMTItYWl8Z2VtaW5pLWRlY2lzaW9ucy1hcGktZGVjaXNpb25zLXdpdGhvdXQtZ2VuZXJhdGlvbnx8aHR0cHM6Ly9ibG9nLmdvb2dsZS9pbm5vdmF0aW9uLWFuZC1haS90ZWNobm9sb2d5L2RldmVsb3BlcnMtdG9vbHMvZ2VtaW5pLWRlY2lzaW9ucy1hcGkvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ" target="_blank" rel="noopener noreferrer">Source: blog.google ↗</a></p>

Google's new [Gemini Decisions API](https://ecommerce-api.datafortress.cloud/r/brieftechnews/sL_ljMKSjUS3YdVZI1do7w/djF8d2VifDIwMjYtMTEtMTItYWl8Z2VtaW5pLWRlY2lzaW9ucy1hcGktZGVjaXNpb25zLXdpdGhvdXQtZ2VuZXJhdGlvbnx8aHR0cHM6Ly9ibG9nLmdvb2dsZS9pbm5vdmF0aW9uLWFuZC1haS90ZWNobm9sb2d5L2RldmVsb3BlcnMtdG9vbHMvZ2VtaW5pLWRlY2lzaW9ucy1hcGkvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) is a different kind of endpoint. Instead of generating tokens, it scores up to 1,000 independent questions against a single multimodal input - text, images, audio, video, PDFs, up to 256K tokens - in one forward pass. It returns probabilities and confidence scores with 150-250 ms end-to-end latency, and it bills zero output tokens.

The model behind it, gemini-decision-1, handles yes/no, multiple choice, and rubric scoring. Google claims it is nearly 5x cheaper than Gemini 3.5 Flash-Lite with the Interactions API. For engineers, this replaces a whole class of token-by-token generation with a calibrated classifier: tool selection, policy checks, model routing, content moderation. If you have been building those as prompt-and-parse loops, this is the thing that kills them.

The tradeoff is that it is closed-set. You get probabilities, not prose. If your pipeline needs an explanation along with the decision, you still need a generative model - but for the decision itself, this is dramatically cheaper and faster.

Runway released [Praxis-1](https://ecommerce-api.datafortress.cloud/r/brieftechnews/TmOkoHG_vKh1TO0Z4C7WhA/djF8d2VifDIwMjYtMTEtMTItYWl8cnVud2F5LXByYXhpcy0xLW9wZW4td2VpZ2h0LXJvYm90aWNzLWhpdHMtdGhlLWxlYWRlcmJvYXJkfHxodHRwczovL3J1bndheS5jb20vbmV3cy9jb21wYW55LW5ld3MvcHJheGlzLTEtaXMtbm93LWF2YWlsYWJsZT91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), a 27B-parameter mixture-of-experts diffusion transformer that predicts video and actions jointly, under Apache 2.0. It tops NVIDIA's RoboLab-120 leaderboard with 46.2% success across 1,200 episodes, beating FLUX 3 Action (42.9%), Cosmos3 Nano (36.8%), and π0.5 (28.0%).

The model runs on NVIDIA hardware from H100/B200 down to RTX 5090 and Jetson Thor, with full fine-tuning and LoRA support. It is on GitHub, Hugging Face, and vLLM-Omni. The interesting number for robotics engineers: it adapts to new embodiments with light fine-tuning, reaching 80.0% success on SimplerEnv with Google's RT-1 robot versus the original 52.4%. That is the difference between a model that works on one robot and a model that works on your robot.

[OpenRouter measured](https://ecommerce-api.datafortress.cloud/r/brieftechnews/zjCVymixjImdHo9osW6C9w/djF8d2VifDIwMjYtMTEtMTItYWl8bWNwLXZzLWNsaS12cy1za2lsbHMtdGhlLWhpZGRlbi1jb3N0LW9mLXRvb2wtZGVmaW5pdGlvbnN8fGh0dHBzOi8vb3BlbnJvdXRlci5haS9ibG9nL2luc2lnaHRzL21jcC12cy1jbGktdnMtc2tpbGxzLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) what giving agents tools actually costs in tokens, and the numbers are brutal. On a GitHub task using Claude Sonnet 5.5, the CLI used 1,421 input tokens, the skill used 3,315, and the GitHub MCP server used 59,417 - its 46 default tools adding 19,436 tokens per request. A single tool result, GitHub's release object, cost about 20,400 tokens.

The mechanism is simple: tool definitions are billed as input tokens on every request. MCP servers that ship dozens of tools inflate context on every single call, whether the agent uses them or not. OpenRouter's Tool Search server cuts the up-front tool cost to under 600 tokens, halving total cost on Sonnet 5.5. If you are running agents in production, this is the difference between a viable unit cost and a bill that eats your margin. The fix is lazy tool loading - defer definitions until the agent actually needs them.
