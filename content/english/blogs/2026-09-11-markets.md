The number that matters today is 69%. Datadog reports that in March 2026 customer traces, 69% of all input tokens were system prompts - static, repeated, cacheable text - and it has now shipped prompt caching for Anthropic and OpenAI models to attack exactly that. This is the rare piece of AI-infrastructure news that is simultaneously an engineering fact and a margin statement: every AI-heavy operator is paying frontier-model rates to re-send the same instructions thousands of times, and the tooling that fixes it sits in observability, not in the model providers' own consoles. That is a genuine second-order read: the model vendors are the obvious names in the AI-cost story, but the beneficiary here is the layer that can see the traces.

> When 69% of your tokens never change, caching stops being an optimization and becomes the business model.

<h2 id="inference-economics-move-from-headline-to-plumbing">Inference economics move from headline to plumbing</h2>

The Datadog finding pairs with two quieter data points in today's material. GitHub Copilot's cost-efficiency experiments showed that shortening tool responses saved local tokens but *increased* global token usage and task time - a clean demonstration that local optimization in agent systems is not global optimization, and that naive context-trimming can backfire. And the Pragmatic Engineer piece on Uber's Minions harness describes companies benchmarking all frontier and open models weekly and caching prompts to save money. Three separate sources converging on the same problem in the same week is what a theme building looks like, not a one-off. The read-through: whoever owns the trace owns the cost lever, which is why the observability names are the non-obvious beneficiaries of the agentic buildout.

<h2 id="cloudflares-quiet-compounding">Cloudflare&#x27;s quiet compounding</h2>

Two Cloudflare items, neither of which will make a headline but both of which deepen the moat. First, the Automatic Key Exchange work that prefers post-quantum hybrid X25519MLKEM768 cut HelloRetryRequests from ~52% to 3.7% and saved over 150ms at p90 on handshakes for hundreds of thousands of domains - post-quantum migration going from tax to non-event is exactly the kind of thing that keeps enterprises from leaving. Second, the rebuilt workerd module registry now supports every stable Node.js API by default, with apps up to 64 MiB. The second-order effect of the Node compatibility story is that it lowers the exit cost from traditional Node hosting - the displaced parties are the commodity app-host incumbents, not the hyperscalers.

<h2 id="agents-that-pay-agents">Agents that pay agents</h2>

Coinbase's Bazaar MCP is a discovery marketplace where AI agents can search for, pay for, and use tools independently via x402. Strip the framing and this is settlement infrastructure for machine-to-machine commerce - the missing piece between "agents everywhere" narratives and agents that can actually transact without a human in the loop. It extends a Coinbase thesis already showing up in fee revenue on the tokenized-equities side. Related, from the same agentic strain: East River Source Control as a possible git successor because agentic development strains current version control - a speculative but real signal that the agent era is starting to break tooling designed for human commit cadence.

<h2 id="capacity-as-a-competitive-fact">Capacity as a competitive fact</h2>
