Exposing real accounts to autonomous software usually fails at authorization boundaries. [Mercury expanded its MCP support](https://ecommerce-api.datafortress.cloud/r/brieftechnews/3_14HrtuoFUo5jlE40-2MQ/djF8d2VifDIwMjYtMTAtMTktZmludGVjaHxtZXJjdXJ5LXBsdWdzLXRoZS1tb2RlbC1jb250ZXh0LXByb3RvY29sLWRpcmVjdGx5LWludG8tYmFuay1yYWlsc3x8aHR0cHM6Ly90aHJlYWRyZWFkZXJhcHAuY29tL3RocmVhZC8yMTEwNzQ0MzIyNDU5MTczMzQ3Lmh0bWw_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) from read-only telemetry into live transactional execution. The architecture isolates preparation from execution. An agent running over the protocol can resolve invoices, map counterparties, and prepare payment payloads via API, but execution halts at an out-of-band human confirmation gate. This model maintains explicit revocable permissions while eliminating the friction of manual bookkeeping.

While the legal terms remain narrow around edge-case hallucinations, it provides the first enterprise-grade indemnity framework for automated commerce, removing commercial chargeback ambiguity for merchants accepting non-human payments.

Mastercard made a parallel move, partnering with crypto-infrastructure provider BVNK to launch the [Global Money Platform](https://ecommerce-api.datafortress.cloud/r/brieftechnews/mYyYWxsDEfrFEsakfI_tRA/djF8d2VifDIwMjYtMTAtMTktZmludGVjaHx2aXNhLWFuZC1tYXN0ZXJjYXJkLWRlcGxveS1wcm9kdWN0aW9uLWdyYWRlLXN0YWJsZWNvaW4tcmFpbHN8fGh0dHBzOi8vd3d3Lm1hc3RlcmNhcmQuY29tL3VzL2VuL25ld3MtYW5kLXRyZW5kcy9wcmVzcy8yMDI2L29jdG9iZXIvbWFzdGVyY2FyZC1hbmQtYnZuay1sYXVuY2gtZ2xvYmFsLW1vbmV5LXBsYXRmb3JtLXRvLXBvd2VyLWEtbXVsdC5odG1sP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ). Exposed as a single REST API, the platform unifies multi-currency fiat ledgers, programmatic stablecoin conversion, crypto-backed cards, and bank rails powered by Mastercard Move. By abstracting conversion and treasury routing, the system gives enterprise software platforms a turn-key interface for global payouts, with an explicit roadmap to support autonomous agent settlement and tokenized bank deposits.
