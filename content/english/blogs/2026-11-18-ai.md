[This write-up](https://ecommerce-api.datafortress.cloud/r/brieftechnews/Zp1XB-dmH7KcRiJ9TSBPvA/djF8d2VifDIwMjYtMTEtMTgtYWl8d2VpZ2h0LXNwYWNlLXByb2dyYW1taW5nLWJ1aWxkaW5nLW5ldHdvcmtzLWxpa2UtaXRzLTE5OTV8fGh0dHBzOi8vbm90ZXNieWxleC5jb20vd2VpZ2h0LXNwYWNlLXByb2dyYW1taW5nLTE5OTBzLmh0bWw_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) of weight-space programming experiments is the most fascinating thing today. The author had Claude Fable 5.2 write all 5,994 weights of a fixed CNN for MNIST classification from scratch - no fitting, no regression, no search. Claude beat Opus 5.5 considerably, and the resulting network used hand-crafted filters and templates straight out of the pre-deep-learning era.

A [second replication](https://ecommerce-api.datafortress.cloud/r/brieftechnews/Vg3uZikzd--jId-eWv6tVA/djF8d2VifDIwMjYtMTEtMTgtYWl8d2VpZ2h0LXNwYWNlLXByb2dyYW1taW5nLWJ1aWxkaW5nLW5ldHdvcmtzLWxpa2UtaXRzLTE5OTV8fGh0dHBzOi8vamFjb2JzdHJhdXNzLmJlYXJibG9nLmRldi9leHBlcmltZW50cy1pbi13ZWlnaHQtc3BhY2UtcHJvZ3JhbW1pbmcvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) confirms the pattern with GPT-6 Astra in a Docker container with no internet, Python, and NumPy only. The model could identify a network's task from raw weights, write a game-playing policy network from scratch, and improve models by editing weights directly.

This is "LLM Descent" - a training loop where frontier models author weights without gradient descent. It's early, but it points at a future where you don't train models, you edit them. That changes what "training" means for anyone running a model stack.

[NVIDIA's post](https://ecommerce-api.datafortress.cloud/r/brieftechnews/xBaSAFmFC70dd_WAqdr60Q/djF8d2VifDIwMjYtMTEtMTgtYWl8bnZpZGlhcy1zcGFyc2UtYXR0ZW50aW9uLXByaW1lci1mb3ItbG9uZy1jb250ZXh0c3x8aHR0cHM6Ly9kZXZlbG9wZXIubnZpZGlhLmNvbS9ibG9nL2NvLWRlc2lnbmluZy1zcGFyc2UtYXR0ZW50aW9uLWZvci1lZmZpY2llbnQtbG9uZy1jb250ZXh0LWluZmVyZW5jZS8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) on co-designing sparse attention is a practical deep dive for anyone pushing past 128K-token contexts. Each query attends to only the k most relevant keys instead of the full context, cutting compute and memory traffic.

The catch: the indexer still scores all N keys, and it takes 47% of prefill time in DeepSeek V3.2. NVIDIA sweeps the design knobs - query heads, compression ratio, speculative-decoding depth - against a production FP8 kernel. If you're building long-context inference, this is the hardware-aware guidance you need to keep indexer and Top-k costs from eating your gains.

[Cerebras' disaggregated inference](https://ecommerce-api.datafortress.cloud/r/brieftechnews/NvHd2peClXVjlRf6sRFTiA/djF8d2VifDIwMjYtMTEtMTgtYWl8Y2VyZWJyYXMtZ29lcy1wcm9kdWN0aW9uLXdpdGgtZGlzYWdncmVnYXRlZC1pbmZlcmVuY2V8fGh0dHBzOi8vd3d3LmNlcmVicmFzLmFpL2Jsb2cvY2VyZWJyYXMtbGF1bmNoZXMtZGlzYWdncmVnYXRlZC1pbmZlcmVuY2U_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) is now in production: GPUs handle prefill, Cerebras Wafer Scale Engines handle decode. The result is five times more tokens per megawatt at ultrafast speeds, available via Cerebras Inference Cloud and for infrastructure partners.

This is a direct answer to the inference capacity crunch from agentic apps like Muse and Copilot. When decode speed is the bottleneck for interactive agents, splitting the pipeline across specialized hardware is the pragmatic move. Cerebras is betting its decode advantage is worth the architectural complexity.
