David Cramer detailed how Sentry automated code refactoring - specifically [porting services to Rust using Opus 5.5 - via their agent named Junior](https://ecommerce-api.datafortress.cloud/r/brieftechnews/PTDizTrTRu8IRyTNcDemGg/djF8d2VifDIwMjYtMTAtMzAtdGVjaHxhZ2VudC1hcmNoaXRlY3R1cmUtZGl0Y2gtcmlnaWQtZ3VhcmRyYWlscy1mb3ItcHItaXRlcmF0aW9ucy1hbmQtZWdyZXNzLXByb3hpZXN8fGh0dHBzOi8vY3JhLm1yL2EtbGl0dGxlLWRldGVybWluaXNtP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ). The central takeaway: hard-coded system prompt constraints degrade LLM problem-solving. Over-prompting models to force determinism creates brittle execution paths. 

Instead of constraining the agent's internal reasoning loop, Sentry runs the agent freely inside an isolated microVM sandbox and controls behavior externally:

```
[Agent Core] <---> [MitM Egress Proxy] <---> [Network / APIs]
                         │
                   (Deny Action)
                         │
                         ▼
        [Automated PR Review Comment Feedback]
```

1. **Egress Interception:** An in-line egress proxy monitors output commands and denies unauthorized actions at the wire.
2. **Review Feedback Loops:** Rather than using special syntax harnesses, the agent receives standard pull request feedback and compiler errors as natural correction prompts.
3. **Execution Over Outlines:** Treating an agent like an external human contributor using standard Git interfaces provides reproducible output without hobbling context windows.

Complementing this, Martin Alderson published an operational guide on [optimizing LLM agent runtimes](https://ecommerce-api.datafortress.cloud/r/brieftechnews/tfC-LfQQ7SHxkhi7Wv5GOg/djF8d2VifDIwMjYtMTAtMzAtdGVjaHxhZ2VudC1hcmNoaXRlY3R1cmUtZGl0Y2gtcmlnaWQtZ3VhcmRyYWlscy1mb3ItcHItaXRlcmF0aW9ucy1hbmQtZWdyZXNzLXByb3hpZXN8fGh0dHBzOi8vbWFydGluYWxkZXJzb24uY29tL3Bvc3RzL21ha2luZy1hZ2VudHMtZmFzdC8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t). His team’s telemetry shows that short, multi-turn tool calling loops are bottlenecked entirely by Time to First Token (TTFT) and prompt caching hit rates, while code synthesis pipelines are bound by output token velocity (tok/s).
