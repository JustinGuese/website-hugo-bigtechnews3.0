Meta’s [Muse Wonder](https://ecommerce-api.datafortress.cloud/r/brieftechnews/O0eOkjjFLfweBpUWwPwsUg/djF8d2VifDIwMjYtMTAtMTMtdGVjaHxtZXRhLXNoaXBzLW11c2Utd29uZGVyLWZvci1wZXJzaXN0ZW50LWFnZW50aWMtZXhlY3V0aW9ufHxodHRwczovL3d3dy50ZXN0aW5nY2F0YWxvZy5jb20vbWV0YS1sYXVuY2hlcy1tdXNlLXdvbmRlci1hbmQtd29uZGVyLWZ1bGwtZm9yLWFpLWFnZW50cy8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) is now live via the Meta Model API and the Muse Code IDE, while the higher-tier Wonder Full remains restricted to Muse Code subscribers. Unlike standard autoregressive models that treat each prompt window as a stateless sandbox, Wonder uses two core mechanisms: Active Memory, which preserves state across sessions, and Active Focus, which acts as a goal-driven loop that autonomously explores alternative approaches when hitting compiler errors or broken unit tests.

The architecture aims straight at long-running software maintenance where standard models degrade as token context expands. By pairing Active Memory retrieval with expanded test-time compute, Meta claims Wonder generalizes better on unfamiliar codebases and requests clarification rather than hallucinating broken dependencies.

In an updated guide on [Cryptographic Right Answers](https://ecommerce-api.datafortress.cloud/r/brieftechnews/0-j5pslfxS-mL63daklPZw/djF8d2VifDIwMjYtMTAtMTMtdGVjaHxwb3N0LXF1YW50dW0tc2VjdXJpdHktZGVhZGxpbmUtcHVsbGVkLWZvcndhcmQtdG8tMjAyOXx8aHR0cHM6Ly93b3Jkcy5maWxpcHBvLmlvL3JpZ2h0LWFuc3dlcnMvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ), cryptographer Filippo Valsorda warned that the industry deadline for transitioning production systems to post-quantum primitives must wrap up by 2029. The acceleration is driven by faster post-quantum development schedules alongside automated LLM-driven vulnerability hunting against legacy implementations.

The baseline requirements now mandate ML-KEM-768 with X25519 for key exchange, ML-DSA-44 for asymmetric digital signatures, HPKE with MLKEM768-X25519 for public-key encryption, and Cobblestone-128 or XAES-256-GCM for symmetric encryption. Symmetric ciphers like AES-256 remain robust, but any infrastructure relying on RSA or classical elliptic-curve signatures requires immediate deprecation plans.

Shopify, OpenAI, and Cloudflare have backed [WebMCP](https://ecommerce-api.datafortress.cloud/r/brieftechnews/tmSgxiEmcZP8dP6XfLNPUQ/djF8d2VifDIwMjYtMTAtMTMtdGVjaHx3ZWJtY3AtcmVwbGFjZXMtZG9tLXNjcmFwaW5nLWZvci1hdXRvbm9tb3VzLWFnZW50c3x8aHR0cHM6Ly9ibG9nLnlvYXYud3MvcG9zdHMvd2h5X3dlYm1jcF9tYXR0ZXJzLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), an emerging protocol that allows browser-based agents to execute structured JavaScript tool calls directly within authenticated sessions. The spec bypasses the traditional approach of parsing DOM structures, reading accessibility trees, or burning inference budgets on computer-vision screenshots.

By offering standardized checkout hooks, WebMCP allows agents to run transactions with low latency while maintaining deterministic control over user sessions. For frontend teams, exposing structured tools directly to user-driven agents removes the overhead of constantly debugging scrapers broken by routine client-side updates.
