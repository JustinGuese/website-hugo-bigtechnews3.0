It arrives alongside a 50% price cut to Claude Sonnet 5.5 cache reads, live across AWS, Google Cloud, and Azure. 

At the same time, the infrastructure around agentic execution is hardening. Microsoft is moving inference off centralized clusters and straight onto endpoint silicon with unified-memory Windows workstations, while AWS is shipping kernel-level sandboxing tools to keep local agent runtimes from running arbitrary shell code.

For teams building tiered agent patterns, the architecture is straightforward: you point code generation, test iteration, and refactoring tasks at Haiku 5.5, keeping Opus 5.5 or Sonnet 5.5 as the upstream planner. If your system relies on heavy retrieval-augmented generation where token ingestion dominates your invoice, the updated pricing makes Haiku 5.5 the default ingestion engine. Anthropic also halved prompt cache read fees for Sonnet 5.5, which directly rewards stacks running long system prompts and stable tool schemas.

Most production agents leak tokens because they blindly query vector databases on every interaction loop. Engineer Mike Chambers published an architecture teardown demonstrating [decider-gated memory](https://ecommerce-api.datafortress.cloud/r/brieftechnews/A7GagvNT8CL_dPkhdWaxsg/djF8d2VifDIwMjYtMTAtMDktaXR8d2h5LXlvdXItYWdlbnQtcGlwZWxpbmVzLXNob3VsZC1zdG9wLXBvbGxpbmctbG9uZy10ZXJtLW1lbW9yeXx8aHR0cHM6Ly9ibG9nLm1pa2VnY2hhbWJlcnMuY29tL3Bvc3RzL2RlY2lkZXItZ2F0ZWQtbWVtb3J5Lz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), using a local 2B-parameter model called strands-decider to evaluate whether an AWS Bedrock agent actually needs external context.

The setup replaces the traditional language model head on a Qwen 3.5-2B torso with a pointer head fine-tuned via LoRA. In testing, the classifier cut Bedrock memory lookups from eight down to three, reducing injected context from 147 database records to just 25 without degrading final output accuracy. Median evaluation latency came in at roughly 115 ms on a desktop RTX 3090 and 153 ms on an Apple Silicon M3 MacBook. The harnesses and code are up on [GitHub](https://ecommerce-api.datafortress.cloud/r/brieftechnews/F-d94_WNKETgIZBvQeiv5g/djF8d2VifDIwMjYtMTAtMDktaXR8d2h5LXlvdXItYWdlbnQtcGlwZWxpbmVzLXNob3VsZC1zdG9wLXBvbGxpbmctbG9uZy10ZXJtLW1lbW9yeXx8aHR0cHM6Ly9naXRodWIuY29tL21pa2VnYy1hd3MvZGVjaWRlci1nYXRlZC1hZ2VudGNvcmUtbWVtb3J5P3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ), offering a drop-in pattern to stop context-window bloating in agentic loops.

Microsoft is restructuring GitHub Copilot to treat local hardware as a primary inference tier. Under an initiative dubbed [Project HydraFusion](https://ecommerce-api.datafortress.cloud/r/brieftechnews/yu0arF_ujAC-VaStU19avQ/djF8d2VifDIwMjYtMTAtMDktaXR8bWljcm9zb2Z0LXJvdXRlcy1naXRodWItY29waWxvdC1hY3Jvc3MtbG9jYWwtcnR4LXNwYXJrLXNpbGljb258fGh0dHBzOi8vY29tbWFuZGxpbmUubWljcm9zb2Z0LmNvbS9sb2NhbC1tb2RlbHMtc2FuZGJveGVkLXRvb2xzLWdpdGh1Yi13aW5kb3dzLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), Copilot will automatically partition workloads between hosted infrastructure and on-device GPUs based on current system load, latency margins, and task complexity.

The on-device component relies on a quantized variant of MAI Code 1.1 Flash, targeted at workstations like the Surface Laptop Ultra packing NVIDIA RTX Spark chips. These systems provide roughly 1 PFLOP of compute alongside up to 128 GB of unified memory, allowing large coding models to stay resident in VRAM without thrashing host memory. To let these local models touch the host safely, Microsoft introduced Microsoft Execution Containers (MXC). MXC acts as an OS-level sandbox that isolates local shell triggers, debugging servers, and workspace disk access, cutting network egress while isolating system credentials.

Expanding on its developer tooling, Microsoft published its broader [hybrid intelligence roadmap](https://ecommerce-api.datafortress.cloud/r/brieftechnews/IPlGI3-HyJ1WOGRwf8xZ4A/djF8d2VifDIwMjYtMTAtMDktaXR8d2luZG93cy1zaGlmdHMtdG8taHlicmlkLWFnZW50LW9yY2hlc3RyYXRpb24td2l0aC1teGN8fGh0dHBzOi8vYmxvZ3Mud2luZG93cy5jb20vd2luZG93c2V4cGVyaWVuY2UvMjAyNi8xMC8wNy9idWlsZGluZy13aW5kb3dzLWZvci1oeWJyaWQtaW50ZWxsaWdlbmNlLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), establishing Windows as an execution broker for autonomous agents. General availability of Microsoft Execution Containers (MXC) brings native sandbox isolation directly into the Windows runtime, aimed squarely at securing deployments for Microsoft Agent 365 and local developer assistants.

Instead of treating background tasks as standard user-space binaries, the operating system routes agent tooling through containerized boundaries with explicit permission barriers for file paths, environment keys, and network routes. The runtime layer supports both Windows ML drivers and direct llama.cpp execution paths, letting IT teams drop offline agents onto DGX Stations, mini-PCs, and unified-memory hardware without exposing the underlying host OS to unsafe tool operations.

SAP announced [SAP Pay](https://ecommerce-api.datafortress.cloud/r/brieftechnews/ghOWHCyNTS2_1jFfFvcL5Q/djF8d2VifDIwMjYtMTAtMDktaXR8c2FwLWVtYmVkcy11c2RjLWFuZC1ldXJjLXNldHRsZW1lbnQtaW50by1jb3JlLWVycC13b3JrZmxvd3N8fGh0dHBzOi8vZm9ya2FzdC5uZXdzL3NhcC1qdXN0LWFkZGVkLXN0YWJsZWNvaW4tc2V0dGxlbWVudC10by10aGUtc29mdHdhcmUtdGhhdC1ydW5zLTg0LW9mLWdsb2JhbC1jb21tZXJjZS8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) at SAP Connect, integrating stablecoin settlement directly into SAP Cloud ERP. The rollout lets corporate treasury teams settle vendor invoices in USDC and EURC across 89 global payment corridors and more than 40 fiat currencies, treating digital assets like standard clearinghouse balance lines.

The integration sits on Circle's Arc blockchain infrastructure, wired into SAP by enterprise connectivity provider Tereina. For enterprise systems engineers, this strips out the custom payment bridges and separate ledger sync jobs usually needed to handle stablecoins. Invoices settle directly against general ledger modules, exposing native APIs for cross-border reconciliation. SAP is also pairing the rails with Joule AI agents to enable automated, policy-gated invoice settlement without requiring manual AP sign-offs.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/fVB-xCIy8WUXj2SVcMh5Dg/djF8d2VifDIwMjYtMTAtMDktaXR8YXdzLXJlbGVhc2VzLXN0cmFuZHMtYm94LXRvLXNhbmRib3gtcm9ndWUtY2xpLWFnZW50c3x8aHR0cHM6Ly93d3cudGhlcmVnaXN0ZXIuY29tL2FpLWFuZC1tbC8yMDI2LzEwLzA3L2F3cy1sYXVuY2hlcy1vcGVuLXNvdXJjZS1haS1hZ2VudC1zYW5kYm94LXRvLXByZXZlbnQteW9sby1tb2RlLWRpc2FzdGVycy81MzAxNjg3P3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ" target="_blank" rel="noopener noreferrer">Source: theregister.com ↗</a></p>

Amazon Web Services launched [Strands Box](https://ecommerce-api.datafortress.cloud/r/brieftechnews/fVB-xCIy8WUXj2SVcMh5Dg/djF8d2VifDIwMjYtMTAtMDktaXR8YXdzLXJlbGVhc2VzLXN0cmFuZHMtYm94LXRvLXNhbmRib3gtcm9ndWUtY2xpLWFnZW50c3x8aHR0cHM6Ly93d3cudGhlcmVnaXN0ZXIuY29tL2FpLWFuZC1tbC8yMDI2LzEwLzA3L2F3cy1sYXVuY2hlcy1vcGVuLXNvdXJjZS1haS1hZ2VudC1zYW5kYm94LXRvLXByZXZlbnQteW9sby1tb2RlLWRpc2FzdGVycy81MzAxNjg3P3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ), an open-source isolation framework designed to intercept unsafe agent actions before they hit host environments. The framework wraps execution runtimes - including the Dogwood Local Engine, Strands Shell, and local Python interpreters - in an ephemeral boundary with state-aware policy enforcement.

Unlike simple permission boundaries, the Strands Box policy engine includes temporal awareness, tracking the sequence of execution rather than isolated actions. It blocks anomalous behavior like an agent generating credentials, modifying a file, and attempting an outbound Slack webhook in the same loop. For infrastructure engineers running unconstrained evaluation loops or tool-using agents locally, it provides an audited security perimeter against catastrophic file deletions and unauthorized API updates.
