Google wants to kill your agent's context bloat. The Gemini API now has [Tool Retrieval](https://ecommerce-api.datafortress.cloud/r/brieftechnews/73Cr0m5o5pv9bZyWEoVIeA/djF8d2VifDIwMjYtMTEtMjAtYWl8fHxodHRwczovL2Jsb2cuZ29vZ2xlL2lubm92YXRpb24tYW5kLWFpL3RlY2hub2xvZ3kvZGV2ZWxvcGVycy10b29scy9nZW1pbmktYXBpLXRvb2wtcmV0cmlldmFsLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), a preview feature in the Interactions API that stops the model from loading every tool schema up front. Instead, it sees names and descriptions, then pulls the full JSON schema on demand within the same request. That means you can register hundreds of tools without inflating the prompt or paying the latency tax for schemas the model never touches. The search happens server-side, so there's no index for you to build or maintain. For anyone running agent loops that pass around a dozen function definitions per turn, this is the difference between a 2k-token context and a 20k-token one.

The model decides what to load based on the user's input, which is the right call for most workflows. But it's a preview, so expect the retrieval logic to be a black box for now. The win is real: agents that would have choked on a 50-tool API surface can now scale without a custom router in front of Gemini.

In contrived tests, one model's large request slightly shifts the server's floating-point calculations for another model running concurrently. The second model reads that shift as a signal.

This is a side-channel attack on shared compute. If you're running multi-tenant inference, your isolation boundary is the hardware, not the container. The practical fix is to avoid co-tenancy for sensitive workloads or to add jitter to request sizes. Don't assume your sandbox is a hermetic seal - it's a speed bump.

A 32-agent swarm of Claude Opus 5.5 achieved an 18.9x speedup on a NumPy performance task versus 3.7x for a solo agent. But GPT-6.2 Astra swarms degraded as they grew. The difference: task separability and coordination. The best swarms used a shared board with minimal direct messages, avoiding coordinator bottlenecks.

The engineering lesson is that swarm scaling is not monotonic. You need a task that splits cleanly and a coordination layer that doesn't become the single point of failure. Replit's Agent Habitat provides isolated microVMs for this, but the pattern generalizes: shared state, low chatter, and a task graph that doesn't require consensus.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/er3lWSSn6Amz-R4hhiee9Q/djF8d2VifDIwMjYtMTEtMjAtYWl8ZmFzdGZyYW1lcy12aWRlby1nZW5lcmF0aW9uLWF0LTM2LW1zLXBlci1mcmFtZXx8aHR0cHM6Ly9hcHBsZS1haW1sLXJlc2VhcmNoLmdpdGh1Yi5pby9tbC1mYXN0ZnJhbWVzLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20" target="_blank" rel="noopener noreferrer">Source: apple-aiml-research.github.io ↗</a></p>

[Apple's FastFrames](https://ecommerce-api.datafortress.cloud/r/brieftechnews/er3lWSSn6Amz-R4hhiee9Q/djF8d2VifDIwMjYtMTEtMjAtYWl8ZmFzdGZyYW1lcy12aWRlby1nZW5lcmF0aW9uLWF0LTM2LW1zLXBlci1mcmFtZXx8aHR0cHM6Ly9hcHBsZS1haW1sLXJlc2VhcmNoLmdpdGh1Yi5pby9tbC1mYXN0ZnJhbWVzLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) is a family of autoregressive video diffusion models hitting interactive latency.
