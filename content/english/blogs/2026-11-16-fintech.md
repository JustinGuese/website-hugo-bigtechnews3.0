[ChatGPT Wallet](https://ecommerce-api.datafortress.cloud/r/brieftechnews/_T8oUlLaSptdP68YbvTEpg/djF8d2VifDIwMjYtMTEtMTYtZmludGVjaHxjaGF0Z3B0LXdhbGxldC1wYXltZW50LXRva2Vucy1ub3QtY2FyZC1udW1iZXJzfHxodHRwczovL29wZW5haS5jb20vaW5kZXgvaW50cm9kdWNpbmctY2hhdGdwdC13YWxsZXQvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) is built with American Express, Mastercard, and Visa, and it uses payment tokens that preserve existing card rewards and dispute protections. The architecture matters: the agent gets a token that can only be used for a specific transaction amount at a specific merchant, not a reusable card number. Each purchase requires biometric approval from the user, which means the agent can't run up a tab while you're asleep.

For engineers, the interesting part is the fraud layer. OpenAI is working with payment processors and fraud providers to help merchants recognize legitimate agent-driven transactions. That's a real problem: when a machine is buying things, the behavioral signals that fraud systems rely on - typing speed, device fingerprints, session patterns - all collapse. Merchants need a way to say "this is an approved agent, not a bot attack."
