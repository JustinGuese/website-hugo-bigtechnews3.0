The model itself matters because of what Google is claiming. Carbon is positioned as its strongest model for cybersecurity, long-horizon agentic workflows, and complex multi-step coding. The benchmark list is specific: #1 on CursorBench 4.0, Perplexity's WANDR, and Zapier's AutomationBench, at more than 2X lower cost per task than the next best external model. For engineers, the practical implication is that you no longer have to choose between a cheap model that fails on long tasks and an expensive one that succeeds. The release also previews [/swarm](https://ecommerce-api.datafortress.cloud/r/brieftechnews/SIS3KVccFEttKGcq2os-DQ/djF8d2VifDIwMjYtMTEtMTEtYWl8Z2VtaW5pLTQtY2FyYm9uLWZyb250aWVyLXJlYXNvbmluZy1hdC1hLWNvbW1vZGl0eS1wcmljZXx8aHR0cHM6Ly9hbnRpZ3Jhdml0eS5nb29nbGUvZG9jcy9zd2FybS8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) in Google Antigravity, which turns a single prompt into a coordinated team of named agents. The coordinator divides the work, assigns workers with public briefs, and adds a verifier that checks diffs and runs tests. Workers run on the same model as the conversation unless specified otherwise, and the coordinator doesn't do technical work itself. The catch is quotas: every worker is its own agent, so swarms burn through quotas much faster than single conversations. If you're building anything that resembles an autonomous coding pipeline, this is worth a weekend experiment.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/qIRrxDne3B5f_Vcg9_3SMQ/djF8d2VifDIwMjYtMTEtMTEtYWl8c3VwcHJlc3NpbmctcmV3YXJkLWhhY2tpbmctd2l0aC13ZWlnaHQtYXJpdGhtZXRpY3x8aHR0cHM6Ly94LmNvbS9LdW5oYW9aL3N0YXR1cy8yMTIwMTcyODYzNzM0ODQ5OTAzP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ" target="_blank" rel="noopener noreferrer">Source: x.com ↗</a></p>

A [researcher's demonstration](https://ecommerce-api.datafortress.cloud/r/brieftechnews/qIRrxDne3B5f_Vcg9_3SMQ/djF8d2VifDIwMjYtMTEtMTEtYWl8c3VwcHJlc3NpbmctcmV3YXJkLWhhY2tpbmctd2l0aC13ZWlnaHQtYXJpdGhtZXRpY3x8aHR0cHM6Ly94LmNvbS9LdW5oYW9aL3N0YXR1cy8yMTIwMTcyODYzNzM0ODQ5OTAzP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) shows you can suppress reward hacking in RL-trained LLMs without touching the reward function. Train two models from the same checkpoint with different reward strictness, and the weight difference acts as a steering vector. Interpolating or extrapolating (e.g., 1.2*A - 0.2*B) amplifies or suppresses the hacking behavior beyond what RL training alone achieves. The concrete result: extrapolating beyond the strict model reduced resource-limit failures from 14.5% to 8% without additional training. This is a clever application of linear mode connectivity and model merging, and it offers an alternative to the painful process of making rewards stricter without breaking correctness.

[Microsoft's MAI-Transcribe-2](https://ecommerce-api.datafortress.cloud/r/brieftechnews/XfRAlSSHBvhD3G17rMYlSw/djF8d2VifDIwMjYtMTEtMTEtYWl8bWFpLXRyYW5zY3JpYmUtMi0wMTAtcGVyLWhvdXItb2YtYXVkaW98fGh0dHBzOi8vbWljcm9zb2Z0LmFpL25ld3MvbWFpLXRyYW5zY3JpYmUtMi1pcy10aGUtZmFzdGVzdC1tb3N0LWFjY3VyYXRlLWFuZC1jaGVhcGVzdC1zcGVlY2gtcmVjb2duaXRpb24tbW9kZWwtaW4tdGhlLXdvcmxkLz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) claims to be the fastest, most accurate, and cheapest speech recognition model on the market. <p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/1G8UtgIFkWrm8BuqT9Ey9A/djF8d2VifDIwMjYtMTEtMTEtYWl8bWV0YXMtZS1tZWFucy1hLWRyb3AtaW4tay1tZWFucy1yZXBsYWNlbWVudHx8aHR0cHM6Ly9naXRodWIuY29tL2ZhY2Vib29rcmVzZWFyY2gvZmFpc3MvdHJlZS9tYWluL2NvbnRyaWIvZV9tZWFucz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20" target="_blank" rel="noopener noreferrer">Source: github.com ↗</a></p>

[Meta FAIR released e-means](https://ecommerce-api.datafortress.cloud/r/brieftechnews/1G8UtgIFkWrm8BuqT9Ey9A/djF8d2VifDIwMjYtMTEtMTEtYWl8bWV0YXMtZS1tZWFucy1hLWRyb3AtaW4tay1tZWFucy1yZXBsYWNlbWVudHx8aHR0cHM6Ly9naXRodWIuY29tL2ZhY2Vib29rcmVzZWFyY2gvZmFpc3MvdHJlZS9tYWluL2NvbnRyaWIvZV9tZWFucz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), a modern replacement for k-means that achieves a ~10x speedup in epochs and wall-clock time while converging to lower loss, with no additional hyperparameters. It uses a mini-batch update rule based on exponential moving averages and ships inside faiss. It runs on CPU with faiss alone and on GPU via PyTorch with Triton/CuTe kernels, though Hopper GPUs (H100/H200) require CUTLASS DSL 4.7.1+ and QuACK 0.6.5+. If you have any k-means in your clustering pipeline, this is a free win.

[Google DeepMind's AlphaProof Code](https://ecommerce-api.datafortress.cloud/r/brieftechnews/BU_dPDpFcu75ucXbMis0Ag/djF8d2VifDIwMjYtMTEtMTEtYWl8YWxwaGFwcm9vZi1jb2RlLXZlcmlmaWVzLXNpZ25hbHx8aHR0cHM6Ly9kZWVwbWluZC5nb29nbGUvYmxvZy9pbnRyb2R1Y2luZy1hbHBoYXByb29mLWNvZGUvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) formally verified key security properties of the actual code underlying the Signal protocol, a first for a widely deployed cryptographic protocol. [ExecuTorch's new WebGPU backend](https://ecommerce-api.datafortress.cloud/r/brieftechnews/RwtrnCdpaZXBMAxTHwmYYQ/djF8d2VifDIwMjYtMTEtMTEtYWl8ZXhlY3V0b3JjaC13ZWJncHUtcHl0b3JjaC1pbi10aGUtYnJvd3Nlcnx8aHR0cHM6Ly9weXRvcmNoLm9yZy9ibG9nL2V4ZWN1dG9yY2gtd2ViZ3B1LXB5dG9yY2gtbW9kZWxzLW9uLXRoZS1ncHUtaW4tdGhlLWJyb3dzZXIvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) lets PyTorch models run in the browser on the GPU with no conversion to another framework's format. A [security report](https://ecommerce-api.datafortress.cloud/r/brieftechnews/B7Yg1mMh_oBCcJ8TgBxBNw/djF8d2VifDIwMjYtMTEtMTEtYWl8MzUwMDAtZ3Jvay1hcHBzLWV4cG9zZWR8fGh0dHBzOi8vYmxvZy5jbGFyb2MuaW8vZ2hvc3RzaGFyZXMtZ3Jvay1idWlsZC1hcHBzP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) found that more than 35,000 apps built with Grok's Build mode were open to anyone with the link, with no sign-in required. The report tested 43,551 Grok app addresses, finding 35,578 (94.7%) of the 37,571 still online were open to anyone. Among the exposed apps: SpaceXSI's own sales territory map, an X ad proposal marked confidential, an ICU patient's lab results, and a hospital group's staff list. This is a default-access failure in AI-generated apps, and it should make anyone shipping a "build an app from a prompt" feature audit their sharing defaults before the press does.
