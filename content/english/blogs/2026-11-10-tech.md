Anthropic's pre-IPO moment is riding on a model that one tester describes as approaching "Jagged AGI." Claude Fable 5.2, tested before public launch, is "almost as good as most human experts at most intellectual tasks that can be completed with a computer," according to [the One Useful Thing review](https://ecommerce-api.datafortress.cloud/r/brieftechnews/QshYX5XWKcGkQTOOqhwGEA/djF8d2VifDIwMjYtMTEtMTAtdGVjaHxjbGF1ZGUtZmFibGUtNTItdGhlLWphZ2dlZC1hZ2ktdGhhdC1zdGlsbC1uZWVkcy1hLWh1bWFufHxodHRwczovL3d3dy5vbmV1c2VmdWx0aGluZy5vcmcvcC9mYWJsZS01Mi1hbmQtamFnZ2VkLWFnaT91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20).

The demo that matters: the author had Fable create an embeddable video in one shot, with no feedback loop. That's creativity and judgment at a human-expert level. But the "jagged" part is real - there are still important areas where the model falls well behind human capability. The point the author makes is that these aren't simple errors or hallucinations anymore. It's a different class of failure, closer to a brilliant but inconsistent colleague than a broken tool.

For engineers, this sets expectations. The models you're integrating into production are no longer just autocomplete engines. They're approaching parity on the tasks you'd hand to a competent contractor. The gaps are now in judgment under ambiguity, not in raw capability. Plan your human oversight accordingly.

Google is [rolling out two new TPU variants](https://ecommerce-api.datafortress.cloud/r/brieftechnews/oDMfxQYd07vlijrkzLwhbA/djF8d2VifDIwMjYtMTEtMTAtdGVjaHxnb29nbGVzLXRwdS1nYW1iaXQtY29uZmlkZW50aWFsLWNvbXB1dGluZy1hbmQtbG9uZy1jb250ZXh0c3x8aHR0cHM6Ly93d3cuYmxvb21iZXJnLmNvbS9uZXdzL2FydGljbGVzLzIwMjYtMTEtMDkvZ29vZ2xlLWVzY2FsYXRlcy1udmlkaWEtcml2YWxyeS13aXRoLW5ldy12ZXJzaW9ucy1vZi1pdHMtdHB1LXN5c3RlbXM_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) aimed squarely at Nvidia's weak spots. The 8tx targets confidential computing - secure, encrypted workloads for government agencies and regulated industries. The 8i Max is built for AI applications that need long-context windows, letting models access a wider range of information when handling queries.

This is the agent era play. Agents need to hold more context, and they need to do it in environments where data sovereignty and encryption are non-negotiable. Google's TPU business has already netted Apple, Meta, and Oracle as clients. These new chips give engineers real alternatives to Nvidia's GPUs for specific workloads - if you're building for regulated industries or running long-context agents, the 8tx and 8i Max are worth benchmarking against whatever Nvidia SKU you're currently renting.

The headline numbers: a 25% smaller package, up to 10x faster context delivery than v10, and type-safe stories across React, Vue, Angular, Web Components, and Svelte.

The interesting part is the architecture. The new `ui-workflow` skill and headless CLI tools let agents query component APIs and docs without spinning up a running Storybook instance. For teams already using agents to write UI code, this removes a real bottleneck: the context-gathering step that used to eat tokens and time. Storybook is positioning itself as the agent's source of truth for component behavior, which is a smart bet if agentic development is going to be the default workflow.

Paul Irish's [chrome-capture](https://ecommerce-api.datafortress.cloud/r/brieftechnews/7uLJRjVhX1VIj2k2ALJJ1g/djF8d2VifDIwMjYtMTEtMTAtdGVjaHxjaHJvbWUtY2FwdHVyZS1uYXRpdmUtMTIwZnBzLXRhYi1yZWNvcmRpbmctbm8tZmZtcGVnfHxodHRwczovL2dpdGh1Yi5jb20vcGF1bGlyaXNoL2Nocm9tZS1jYXB0dXJlP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) leverages the new `Page.startScreenRecording` API (landed September 2026) to record Chrome tabs at 60 - 120fps, up to 2160p, straight to an AV1 .mp4 file - tab audio included, no ffmpeg required.

The mechanics are interesting: frames go from the compositor to an out-of-process encoder over shared memory, which makes stopping near-instant. The CLI runs headless for ≤60fps and switches to headful on macOS for >60fps to lock onto ProMotion's 120Hz display. Puppeteer v25.10+ wraps it as experimental `page.record()`, and Playwright has an open PR.

For anyone who's fought with screen recording pipelines - capture, encode, mux, sync audio - this removes an entire class of tooling. If you're building demo tools, testing suites, or anything that needs high-fidelity browser capture, this is the new baseline.

The difference is in the fallback position.

Meta's core is advertising, with a bet on Meta Superintelligence Labs (MSL). If that bet fails, the ads business still prints money. Anthropic's core is a fast-growing API, with a bet on first-party products. If the API growth stalls, there's no safety net. The uncomfortable truth: Meta can be wrong about AI and survive. Anthropic can't. That asymmetry is why investors are pushing for a lower IPO price, and why the IPO is still happening anyway - the window may close.
