AWS has become the first hyperscaler approved to handle 'NATO Restricted' (NR) classified information. The [accreditation](https://ecommerce-api.datafortress.cloud/r/brieftechnews/Rqk34oOmL4xidkUr8tOGmg/djF8d2VifDIwMjYtMDktMjUtaXR8YXdzLWdldHMtdGhlLW5hdG8tc3RpY2tlcnx8aHR0cHM6Ly93d3cuaXRwcm8uY29tL2Nsb3VkL2Nsb3VkLWNvbXB1dGluZy9hd3MtYmVjb21lcy1maXJzdC1oeXBlcnNjYWxlci10by1zZWN1cmUtbmF0by1yZXN0cmljdGVkLWFwcHJvdmFsLWFzLWFsbGlhbmNlLW1lbWJlcnMtdGFyZ2V0LXJlc2lsaWVudC1hbmQtYWdpbGUtaW5mcmFzdHJ1Y3R1cmU_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) means NATO member states and defense partners can host sensitive workloads in any of AWS's 15 Regions located in member nations.

This is a big deal for anyone running defense or public-sector workloads. It provides a common security baseline and an accelerated path to national accreditation, plus access to the AWS Trusted Secure Enclave - Sensitive Edition. For engineers, this opens a new compliance path on commercial cloud infrastructure that previously required dedicated or sovereign offerings. The evaluation was done by Spain's National Cryptographic Centre, which adds a layer of trust that other hyperscalers will have to match.

The integration combines Row Zero's familiar interface with Databricks' governance stack, including Genie Ontology, Unity Catalog, and Unity Gateway. A paper from [Berkeley and Stanford](https://ecommerce-api.datafortress.cloud/r/brieftechnews/vZWBH-Q_YZNjSfulmkujWg/djF8d2VifDIwMjYtMDktMjUtaXR8dGhlLWRhdGFiYXNlLXJlc2VhcmNoZXJzLWV4aXN0ZW50aWFsLXF1ZXN0aW9ufHxodHRwczovL2VtcHR5c3F1YS5yZS9ibG9nL3Jldmlldy13aGF0LWhhcHBlbnMtd2hlbi10aGUtbW9kZWwtZWF0cy10aGUtc3RhY2svP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) argues that as foundation models improve, they natively reduce the inefficiency of agent-issued queries. This challenges prior work that predicted databases would be bottlenecked by speculative agent workloads.

The authors propose a research agenda for adapting databases for AI usage, but the reviewer is skeptical that AI will leave meaningful work for database researchers. The core question for engineers: can current database architectures, designed for repetitive OLTP, handle heterogeneous agent queries without a redesign? If the models get smart enough to write efficient queries, the database might not need to change at all. If not, we're in for a decade of painful middleware.

UiPath launched [Cartographer and its Map of Work](https://ecommerce-api.datafortress.cloud/r/brieftechnews/lYnUlNF4naKQqgJIRvwweg/djF8d2VifDIwMjYtMDktMjUtaXR8dWlwYXRoLXdyaXRlcy10aGUtbWFudWFsLWFpLW5ldmVyLWhhZHx8aHR0cHM6Ly9kaWdpbm9taWNhLmNvbS91aXBhdGgtbWFwcy1taXNzaW5nLWxheWVyLWVudGVycHJpc2UtYWktY2FydG9ncmFwaGVyP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) at FUSION 2026. For engineers, this addresses the gap between LLM memory and true learning, which is critical for reliable AI agents in production. It's a bet that the missing layer isn't more model capability, but better context.

Docker introduced [Cloud Sandboxes](https://ecommerce-api.datafortress.cloud/r/brieftechnews/cDDuZpf8PREq8MG21kd_cw/djF8d2VifDIwMjYtMDktMjUtaXR8ZG9ja2VyLW1ha2VzLWFnZW50cy1ydW4tb3Zlcm5pZ2h0fHxodHRwczovL3d3dy5kb2NrZXIuY29tL2Jsb2cvaW50cm9kdWNpbmctY2xvdWQtc2FuZGJveGVzLXN0YXJ0LW9uLXlvdXItbGFwdG9wLWZpbmlzaC1pbi10aGUtY2xvdWQvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ), extending its microVM-based sandbox to run on Docker-managed compute. Pricing starts at $0.07 per hour. For engineers, this addresses the shift to long-horizon agent tasks that need always-on, scalable compute with the same isolation model as local sandboxes. It's a pragmatic answer to the "my laptop died and my agent was mid-task" problem.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/mkFLprHnBo1__7HKYD4h9g/djF8d2VifDIwMjYtMDktMjUtaXR8cGluZWNvbmVzLWRhdGEtcGxhbmUtZ29lcy1ieW9jfHxodHRwczovL3d3dy5waW5lY29uZS5pby9ibG9nL2J5b2MtZ2VuZXJhbGx5LWF2YWlsYWJsZS8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t" target="_blank" rel="noopener noreferrer">Source: pinecone.io ↗</a></p>

Pinecone announced general availability of [Bring Your Own Cloud (BYOC)](https://ecommerce-api.datafortress.cloud/r/brieftechnews/mkFLprHnBo1__7HKYD4h9g/djF8d2VifDIwMjYtMDktMjUtaXR8cGluZWNvbmVzLWRhdGEtcGxhbmUtZ29lcy1ieW9jfHxodHRwczovL3d3dy5waW5lY29uZS5pby9ibG9nL2J5b2MtZ2VuZXJhbGx5LWF2YWlsYWJsZS8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) on AWS, Google Cloud, and Azure. Customers can now run Pinecone's data plane inside their own cloud account and region.

The architecture separates the control plane (which handles management and doesn't store customer data) from the data plane (which stores and processes vectors, documents, and payloads). It uses a zero-access model with no SSH, VPN, or standing IAM roles. For engineers, this enables sensitive AI workloads to stay within customer-controlled boundaries while offloading platform operations to Pinecone. The outbound, pull-based mechanism means Pinecone manages upgrades and scaling without requiring standing inbound access.

<h2 id="kubernetes-patches-a-windows-ntlm-hole"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/K8JHagMs-a19dY21T3WoTw/djF8d2VifDIwMjYtMDktMjUtaXR8a3ViZXJuZXRlcy1wYXRjaGVzLWEtd2luZG93cy1udGxtLWhvbGV8fGh0dHBzOi8vZnJlZW5vZGUubmV0L2FydGljbGUva3ViZXJuZXRlcy1wYXRjaGVzLXdpbmRvd3Mta3ViZWxldC1udGxtLWNvZXJjaW9uLXZpYS1zdWJwYXRoP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ" target="_blank" rel="noopener noreferrer">Kubernetes Patches a Windows NTLM Hole</a></h2>

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/K8JHagMs-a19dY21T3WoTw/djF8d2VifDIwMjYtMDktMjUtaXR8a3ViZXJuZXRlcy1wYXRjaGVzLWEtd2luZG93cy1udGxtLWhvbGV8fGh0dHBzOi8vZnJlZW5vZGUubmV0L2FydGljbGUva3ViZXJuZXRlcy1wYXRjaGVzLXdpbmRvd3Mta3ViZWxldC1udGxtLWNvZXJjaW9uLXZpYS1zdWJwYXRoP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ" target="_blank" rel="noopener noreferrer">Source: freenode.net ↗</a></p>

Kubernetes patched [CVE-2026-76654](https://ecommerce-api.datafortress.cloud/r/brieftechnews/K8JHagMs-a19dY21T3WoTw/djF8d2VifDIwMjYtMDktMjUtaXR8a3ViZXJuZXRlcy1wYXRjaGVzLWEtd2luZG93cy1udGxtLWhvbGV8fGh0dHBzOi8vZnJlZW5vZGUubmV0L2FydGljbGUva3ViZXJuZXRlcy1wYXRjaGVzLXdpbmRvd3Mta3ViZWxldC1udGxtLWNvZXJjaW9uLXZpYS1zdWJwYXRoP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ), a medium-severity flaw (CVSS 5.8) in the Windows kubelet. It allows NTLM coercion via a crafted symlink in a pod volume's subPath resolving to a UNC path.

The kubelet would authenticate to an attacker-controlled share, leaking its NetNTLMv2 hash, which could be cracked or relayed to impersonate a domain-joined node. Fixed builds are 1.34.12, 1.35.9, 1.36.5, and 1.37.1, which refuse UNC symlink targets on Windows. If you're running Windows kubelets, upgrade immediately. This is a reminder that the Windows node is often the weakest link in a Kubernetes cluster.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/yn4e8i6sytJDnMHWYRta_g/djF8d2VifDIwMjYtMDktMjUtaXR8YW5kby13YW50cy10by1yZXBsYWNlLXNsYWNrLXdpdGgtYWdlbnRzfHxodHRwczovL3RlY2hjcnVuY2guY29tLzIwMjYvMDkvMjQvYW5kby1leWVzLXNsYWNrLWFzLWl0LWJ1aWxkcy10ZWFtLW1lc3NhZ2luZy1wbGF0Zm9ybS1mb3ItaHVtYW5zLWFuZC1hZ2VudHMtdG8td29yay10b2dldGhlci8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t" target="_blank" rel="noopener noreferrer">Source: techcrunch.com ↗</a></p>

Ando, a startup founded by Sara Du, emerged from stealth with a [team messaging platform](https://ecommerce-api.datafortress.cloud/r/brieftechnews/yn4e8i6sytJDnMHWYRta_g/djF8d2VifDIwMjYtMDktMjUtaXR8YW5kby13YW50cy10by1yZXBsYWNlLXNsYWNrLXdpdGgtYWdlbnRzfHxodHRwczovL3RlY2hjcnVuY2guY29tLzIwMjYvMDkvMjQvYW5kby1leWVzLXNsYWNrLWFzLWl0LWJ1aWxkcy10ZWFtLW1lc3NhZ2luZy1wbGF0Zm9ybS1mb3ItaHVtYW5zLWFuZC1hZ2VudHMtdG8td29yay10b2dldGhlci8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) designed for both humans and AI agents. It's positioning itself as a full Slack replacement.

The app gives agents their own identities and inboxes, lets them join channels and conversations without being tagged, and can message humans proactively.
