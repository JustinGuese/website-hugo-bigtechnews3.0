A developer built [Qwenputer](https://ecommerce-api.datafortress.cloud/r/brieftechnews/cEmqI0sW757Nhzi3Rbf6kQ/djF8d2VifDIwMjYtMTAtMjktYWl8cnVubmluZy1yaXNjLXYtaW5zaWRlLXF3ZW4tMzUtYXR0ZW50aW9uLWxheWVyc3x8aHR0cHM6Ly9kaXZhZ3IuY29tL2Jsb2cvcXdlbnB1dGVyP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ), which embeds an entire, deterministic RISC-V processor directly into the weight tensors of an unmodified Qwen 3.5 4B model. The execution requires zero external interpreters, tool calls, or Python runtime environments; the compute happens entirely inside the model's native tensor math.

The trick exploits the linear recurrence properties of the architecture's Gated DeltaNet (GDN) layers. By fixing the decay gate and write beta values to exactly 1 and routing state through one-hot key addressing, the developer converted the attention mechanism into an addressable, persistent read/write RAM. The model evaluates arbitrary arithmetic, runs compiled C, and executes MicroPython across successive token generations. For security researchers, this is a clean proof-of-concept for running sandboxed logic inside model weights - or hiding reasoning steps from standard chain-of-thought monitoring.
