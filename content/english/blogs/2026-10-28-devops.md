If you have long-lived GitHub personal access tokens floating around your CI pipelines or developer machines, rotate them this morning. An automated campaign dubbed Gheist has been systematically walking compromised credentials across private and enterprise repositories to turn GitHub Actions into an internal data exfiltration network. 

The attacker's technique avoids external command-and-control servers entirely. By committing workflows that encode secrets to bypass native log masking and reading the raw logs back via the GitHub API, the operation runs silently within GitHub's own infrastructure boundaries.

Meanwhile, the infrastructure underneath Git itself is undergoing the biggest architectural overhaul in its history. AI agents are pushing write volumes past the physical limits of traditional bare-metal datacenters, forcing GitHub to migrate almost every byte it hosts into public cloud storage.

Wiz Research disclosed [Gheist](https://ecommerce-api.datafortress.cloud/r/brieftechnews/S92z1Hd76rEieEWsGPplYQ/djF8d2VifDIwMjYtMTAtMjgtZGV2b3BzfGdoZWlzdC13ZWFwb25pemVzLWdpdGh1Yi1hY3Rpb25zLXRocm91Z2gtYmFzZTMyLWxvZy1ldmFzaW9ufHxodHRwczovL3d3dy53aXouaW8vYmxvZy9naGVpc3QtYXR0ZW1wdGVkLXNjYWxlZC1hYnVzZS1vZi1zdG9sZW4tZ2l0aHViLXRva2Vucy1zdHVtYmxlcz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20), an automated campaign that abuses compromised GitHub credentials to harvest repository secrets. Since mid-September, the operators have targeted over 850 accounts and generated more than 13,500 branches.

The attack mechanics are simple and effective. The automation pushes a branch named `ci-sync-*` containing a malicious workflow at `.github/workflows/sync-check.yml`. When run, the workflow dumps environment variables and repository secrets. To bypass GitHub's default log scrubber - which redacts strings matching known secret patterns - the payload base32-encodes the dumped values before printing them to standard out. 

Instead of opening an egress connection to an external server, which might trigger network alerts, the actor uses the GitHub REST API to pull the workflow execution logs directly. While GitHub added guardrails that blunted the campaign across public repositories, private and enterprise repos remain vulnerable if an identity with write access is compromised. Check your audit logs for unauthorized branch creations matching `ci-sync-*` immediately.

Faced with physical power envelopes and supply chain bottlenecks in its own datacenters, [GitHub moved a copy of 99.99999% of its Git repositories to Azure](https://ecommerce-api.datafortress.cloud/r/brieftechnews/Y3sR8WVz0tgY5fzzRf_Zlw/djF8d2VifDIwMjYtMTAtMjgtZGV2b3BzfGdpdGh1Yi1taWdyYXRlcy05OTk5OTk5LW9mLXJlcG9zaXRvcmllcy10by1henVyZS1mb3ItYWdlbnQtd3JpdGUtc2NhbGV8fGh0dHBzOi8vZ2l0aHViLmJsb2cvZW5naW5lZXJpbmcvYXJjaGl0ZWN0dXJlLW9wdGltaXphdGlvbi90aGUtYnJpZGdlLXRvLWFnZW50LXNjYWxlLWdpdC1pbmZyYXN0cnVjdHVyZS8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t). Running in production since August 2025, the new topology splits five replicas per repository: three on bare-metal and two in Azure, with the Azure footprint already handling half of all Git traffic.

The hard engineering problem was write latency. Git typically relies on repository-wide locks during write operations. Across cross-region topologies, write serialization causes throughput to collapse under the weight of AI coding agents opening hundreds of concurrent branches and pull requests. GitHub resolved this by decoupling storage from compute and shifting to per-reference quorums. Writes to different branches or tags no longer contend for the same repository-level lock, reducing latency to 25ms and delivering 3x to 4x higher write throughput.

Kubernetes scaling controllers operate under decoupled, asynchronous reconciliation loops. When you combine the Horizontal Pod Autoscaler (HPA), Vertical Pod Autoscaler (VPA), KEDA, and Karpenter on the same cluster, those loops quickly trigger resource thrashing, as detailed by [The New Stack's analysis on autoscaler contention](https://ecommerce-api.datafortress.cloud/r/brieftechnews/OwtSxvPDQ9Lk81sOXn8LYg/djF8d2VifDIwMjYtMTAtMjgtZGV2b3BzfHN0b3AtbGV0dGluZy1rdWJlcm5ldGVzLWF1dG9zY2FsZXJzLWZpZ2h0LWZvci10aGUtc2FtZS1maWVsZHN8fGh0dHBzOi8vdGhlbmV3c3RhY2suaW8vd2h5LWt1YmVybmV0ZXMtYXV0b3NjYWxlcnMtZmlnaHQvP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ).

The issue stems from controllers mutating the same API fields without shared context. VPA changes CPU and memory requests to right-size pods, which alters the utilization percentages HPA relies on to calculate target replica counts. Simultaneously, KEDA scales replicas based on external message queues, and Karpenter provisions or consolidates underlying EC2 nodes based on pending pod specs. 

The resulting race conditions cause GitOps drift, eviction loops, and resource ping-pong. Kurup argues that treating scaling as independent Unix-style pipes is broken; platform teams require autonomous, predictive scaling engines that calculate replica counts, pod dimensions, and node capacity inside a single decision loop.

Platform teams rolling out internal developer portals are shifting architectures to accommodate non-human contributors. A guide from [Spacelift on building Golden Paths](https://ecommerce-api.datafortress.cloud/r/brieftechnews/e-POS9m-6yIm8AbT46qHQg/djF8d2VifDIwMjYtMTAtMjgtZGV2b3BzfGdvbGRlbi1wYXRocy1yZXF1aXJlLXN0cmljdC1ib3VuZGFyaWVzLWZvci1haS1hZ2VudHN8fGh0dHBzOi8vc3BhY2VsaWZ0LmlvL2Jsb2cvZ29sZGVuLXBhdGhzLWluLXBsYXRmb3JtLWVuZ2luZWVyaW5nP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) outlines how self-service infrastructure blueprints must evolve when both developers and autonomous coding agents call them.

A functional golden path requires five building blocks: standardized Infrastructure as Code (IaC) modules, CI/CD pipeline definitions, policy-as-code guardrails, documentation, and a developer portal entry. When exposing paths to AI agents via APIs or Model Context Protocol (MCP) servers, loosely defined free-text interfaces lead to misconfigured cloud primitives. Platforms must enforce typed inputs, deterministic schemas, and least-privilege service identities so agents can provision resources like Multi-AZ databases without bypassing compliance guardrails.
