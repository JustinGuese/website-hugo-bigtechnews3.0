OpenAI and Cisco [launched Shirudo](https://ecommerce-api.datafortress.cloud/r/brieftechnews/qa3zD4CPyk0W4Z4rR4PCtw/djF8d2VifDIwMjYtMTEtMjUtaXR8c2hpcnVkby1wYXRjaGluZy10aGUtcGF0Y2gtZ2FwfHxodHRwczovL29wZW5haS5jb20vaW5kZXgvaW50cm9kdWNpbmctc2hpcnVkby8_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t), an open-source runtime that uses eBPF to protect running Linux systems from vulnerabilities without waiting for patches or restarts. <p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/JXQsLGFv4FmAwj-7OmVVRg/djF8d2VifDIwMjYtMTEtMjUtaXR8dGhlLW1pbGxpb24tbGluZS1sbG0tdHJhbnNsYXRpb24tcXVlc3Rpb258fGh0dHBzOi8vdG9tYXNzZXR0aS5tZS9sZWdhY3ktbW9kZXJuaXphdGlvbi1sbG1zLWxhcmdlLXRyYW5zbGF0aW9uLWNvbnNpc3RlbmN5Lz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20" target="_blank" rel="noopener noreferrer">Source: tomassetti.me ↗</a></p>

Can a large LLM-based legacy modernization produce internally consistent code? [This analysis](https://ecommerce-api.datafortress.cloud/r/brieftechnews/JXQsLGFv4FmAwj-7OmVVRg/djF8d2VifDIwMjYtMTEtMjUtaXR8dGhlLW1pbGxpb24tbGluZS1sbG0tdHJhbnNsYXRpb24tcXVlc3Rpb258fGh0dHBzOi8vdG9tYXNzZXR0aS5tZS9sZWdhY3ktbW9kZXJuaXphdGlvbi1sbG1zLWxhcmdlLXRyYW5zbGF0aW9uLWNvbnNpc3RlbmN5Lz91dG1fc291cmNlPWJyaWVmLXRlY2gtbmV3cy5jb20) translated 600,000 lines of RPG/DDS/CL into over one million lines of Java across 49 separate agent sessions, using Claude Code with Opus 5.5. All 5,737 Java files were measured, and despite sessions acting as "49 translators who never talk to each other," the output appeared consistent at first sight.

The newsletter's own summary notes significant consistency issues: independent sessions fail to refactor earlier work, introduce style drift, and rewrite duplicate utility helpers instead of using shared runtime components. The LLM also created Python code generators that converted most declarative assets but left subtle behavioral discrepancies. For anyone considering LLM-based modernization, the answer is: it looks consistent, but it is not.

Cloudflare [extended its Flamingo testing framework](https://ecommerce-api.datafortress.cloud/r/brieftechnews/i6bUw31a4AIFmJK7tUzs9Q/djF8d2VifDIwMjYtMTEtMjUtaXR8cHJvYmluZy1kbnMtYXQtY2xvdWRmbGFyZXx8aHR0cHM6Ly9ibG9nLmNsb3VkZmxhcmUuY29tL3Byb2JpbmctZG5zLWF0LWNsb3VkZmxhcmU_dXRtX3NvdXJjZT1icmllZi10ZWNoLW5ld3MuY29t) to probe DNS from every data center against production, after a scheduling bug left record changes unpublished for hours. Flamingo runs hundreds of millions of tests daily and now measures DNS propagation, using results to decide whether releases proceed or roll back. This catches slow, partial, network-wide DNS failures that unit tests miss - the kind that take down a service without a single error in your CI.

<p class="small mb-4"><a href="https://ecommerce-api.datafortress.cloud/r/brieftechnews/-dktmB3ugcn0gqn1y_2uLQ/djF8d2VifDIwMjYtMTEtMjUtaXR8d29ya2RheS1wYXlyb2xsLWRpdmVyc2lvbi1hdC1tYWNoaW5lLXNwZWVkfHxodHRwczovL3d3dy5yZWNvLmFpL2Jsb2cvaW5zaWRlLWEtbWFjaGluZS1zcGVlZC13b3JrZGF5LXBheXJvbGwtZGl2ZXJzaW9uLWNhbXBhaWduP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ" target="_blank" rel="noopener noreferrer">Source: reco.ai ↗</a></p>

An [AI-assisted payroll-diversion campaign](https://ecommerce-api.datafortress.cloud/r/brieftechnews/-dktmB3ugcn0gqn1y_2uLQ/djF8d2VifDIwMjYtMTEtMjUtaXR8d29ya2RheS1wYXlyb2xsLWRpdmVyc2lvbi1hdC1tYWNoaW5lLXNwZWVkfHxodHRwczovL3d3dy5yZWNvLmFpL2Jsb2cvaW5zaWRlLWEtbWFjaGluZS1zcGVlZC13b3JrZGF5LXBheXJvbGwtZGl2ZXJzaW9uLWNhbXBhaWduP3V0bV9zb3VyY2U9YnJpZWYtdGVjaC1uZXdzLmNvbQ) targeted Workday accounts at multiple organizations since early October 2026. Attackers submitted new bank accounts in as little as 10 seconds (median ~30 seconds) after sign-in, using stolen sessions rather than identity provider sign-ins. Sessions stayed open for up to a day, and telemetry shows rigid browser scripting with invariant two-second pauses - suggesting automation, likely AI-assisted.

This is not a Workday vulnerability; it is stolen credentials used against the app. The lesson is to hunt for machine-speed session anomalies and secure bank-detail changes as if they were credentials themselves.
